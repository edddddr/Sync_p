# MVP Roadmap

## Phase 1

1. Backend foundation with Docker, PostgreSQL, Redis, DRF, JWT, Channels, and Celery.
2. User accounts, profiles, and follow relationships.
3. Places and posts with image upload support.
4. Comments, likes, bookmarks, and ratings.
5. Explore feed, user search, place search, and trending places.
6. Database-backed notifications.

## Later

- WebSocket notifications.
- PostGIS radius search and richer map interactions.
- Recommendation ranking.
- Separate services only after clear scaling pressure appears.
